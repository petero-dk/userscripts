## Installation and Updates

Install a userscript manager such as [Tampermonkey](https://www.tampermonkey.net/) or [Violentmonkey](https://violentmonkey.github.io/), then select a script's **Install** link and confirm installation.

Each script includes automatic update URLs. Update checks follow your userscript manager's settings.
